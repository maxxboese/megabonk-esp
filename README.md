# Megabonk ESP Mod (Melon Loader)

A Mod for Megabonk that highlights all objects with a text label

See below for the modified melon installer that does it all for you automatically

## Features

- GUI Interface to Filter Objects 
- Live 0 Delay object filtering and rendering 
- Safe to use with leaderboard

## How to Install
- Download the Melonloader installer
- Select Megabonk
- Go to game directory and locate the mods folder
- Drag the dll into the mods folder
- Load the game
